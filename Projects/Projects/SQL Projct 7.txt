Task 1 — Number All Orders
Create a query that returns:
order_id
customer_id
order_date
row_number
Requirements:
newest order = 1
oldest order gets the highest number
Your job
Use:
ROW_NUMBER()
OVER()
ORDER BY
-------------------------------------------------------
QUERY:
SELECT 
	order_id,
	customer_id,
	order_date,
ROW_NUMBER() OVER( ORDER BY order_date DESC)
FROM customer_orders;

Ab requirement change:

	c.customer_name,
	co.order_id,
	co.order_date,
ROW_NUMBER() OVER(PARTITION BY order_id ORDER BY order_date )
FROM customers AS c
INNER JOIN customer_orders AS co

Task 3 — Latest Order Only
Sirf har customer ka latest order show karo.
Expected:
customer_name
order_id
order_date
Data Engineering thinking
Yeh pattern real-world pipelines mein bohat common hai:
"Latest record per entity"
For example:
latest customer record
latest transaction
latest API record
latest status
latest event
--------------------------------------------------------------------
QUERY:
SELECT 
* 
FROM
	(SELECT 
		c.customer_name,
		co.order_id,
		co.order_date,
	ROW_NUMBER() OVER(PARTITION BY c.customer_id ORDER BY co.order_date )
	FROM customers AS c
	INNER JOIN customer_orders AS co
	ON c.customer_id = co.customer_id)  AS t 
WHERE row_number = 1;

Task 4 — Rank Orders by Value
Product price ko join karke:
order_value = quantity × price
calculate karo.
Then:
Highest-value order ko rank #1 do.
Output:
order_id
customer_name
order_value
rank
Use:
RANK()
------------------------------------------------------------------------------
QUERY:
SELECT 
	co.order_id,
	c.customer_name,
	(p.price * co.quantity) AS order_value,
RANK() OVER (ORDER BY (p.price * co.quantity) DESC)
FROM customers AS c
INNER JOIN customer_orders AS co
ON c.customer_id = co.customer_id
INNER JOIN products AS p
ON p.product_id = co.product_id;

Task 5 — Rank Customers Within Their City 
Customer spending calculate karo.
Then:
Har city ke andar customers ko total spending ke according rank karo.
Example:
Lahore
Ali       150000 → 1
Ayesha     90000 → 2
Hira       50000 → 3
But Islamabad ka ranking phir se 1 se start hona chahiye.
Yahan tumhein combine karna hoga:
PARTITION BY city
ORDER BY total_spending DESC
--------------------------------------------------------------------------------
QUERY:
SELECT 
    city,
    customer_name,
    total_spending,
    DENSE_RANK() OVER(
        PARTITION BY city 
        ORDER BY total_spending DESC
    ) AS city_rank
FROM (
    SELECT 
        c.customer_id,
        c.customer_name,
        c.city,
        SUM(p.price * co.quantity) AS total_spending
    FROM customers AS c
    INNER JOIN customer_orders AS co
        ON c.customer_id = co.customer_id
    INNER JOIN products AS p
        ON p.product_id = co.product_id
    GROUP BY 
        c.customer_id,
        c.customer_name,
        c.city
) AS customer_spending
ORDER BY 
SUM(total_spending) OVER(PARTITION BY city) DESC,
    city_rank ASC;
