Final Challenge — E-commerce Order Report

Build one professional report containing:

Column
order_id
customer_name
customer_city
product_name
category
quantity
price
order_value
order_date
status

Requirements:

✅ Use multiple JOINs
✅ Calculate order_value
✅ Include only orders with quantity ≥ 2
✅ Exclude Cancelled orders
✅ Sort by order_value DESC

⭐ Bonus

Add a classification:

order_value < 5000       → Small
5000–20000               → Medium
20001–50000              → Large
>50000                   → Premium

QUERY = SELECT 
	co.order_id,
	c.customer_name,
	c.city,
	p.product_name,
	p.category,
	co.quantity,
	p.price,
	co.quantity * p.price AS order_value,
	co.order_date,
	co.status,
CASE
	WHEN (co.quantity * p.price) > 50000 THEN 'Premium'
	WHEN (co.quantity * p.price) BETWEEN 21002 AND 50000 THEN 'Large'
	WHEN (co.quantity * p.price) BETWEEN 5000 AND 20000 THEN 'Medium'
	WHEN (co.quantity * p.price) < 5000 THEN 'Small'
END AS classification	
FROM customers AS c
INNER JOIN customer_orders AS co
	ON c.customer_id = co.customer_id
INNER JOIN products AS p
	ON co.product_id = p.product_id	

WHERE (co.quantity >= 2) AND (co.status != 'Cancelled') 
ORDER BY (co.quantity * p.price) DESC
