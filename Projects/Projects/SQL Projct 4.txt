Task 5 — Combine CASE + WHERE

Find only orders where:

status is Pending OR Shipped
amount > 7000

Then create:

order_size

Rules:

<= 10000 → Medium

10000 → Large

Sort by amount highest → lowest.
QUERY = SELECT order_id, customer_name, total_amount, status,
CASE 
    WHEN total_amount > 10000 THEN 'Large'
    ELSE 'Medium'
END AS order_size
FROM 
orders
WHERE (status = 'Pending' OR status = 'Shipped') AND total_amount > 7000
ORDER BY total_amount DESC
